# Spec: 05.5 - Navegación Minimalista

## 1. Descripción

Micro-rebanada intercalada entre la spec 05 (walk-ins/timers) y la 06
(agenda). Hasta ahora cada pantalla del dashboard era una isla sin forma de
navegar entre ellas salvo escribiendo la URL a mano. Esta spec conecta el
dashboard con una barra de navegación inferior fija (mobile-first, estilo
app nativa) y ordena las pantallas de gestión (Servicios, Equipo) detrás de
un ítem "Más", en vez de sumarlas a la barra principal.

## 2. Íconos y destinos de la barra

4 ítems fijos, usando [`lucide-react`](https://lucide.dev/):

| Ítem     | Ícono           | Ruta             |
| -------- | --------------- | ---------------- |
| Inicio   | `Home`          | `/inicio`        |
| Caja     | `Wallet`        | `/caja`          |
| Agenda   | `Calendar`      | `/agenda`        |
| Más      | `MoreHorizontal`| `/mas`           |

`Estadísticas` y las pantallas de gestión (`Servicios`, `Equipo`) quedan
fuera de la barra principal a propósito: no son de uso constante como
Inicio/Caja/Agenda. `Servicios` y `Equipo` van dentro de `/mas`;
`Estadísticas` queda pendiente de un lugar definitivo hasta que tenga
lógica real (spec 08).

## 3. Archivos a crear / modificar

- `package.json`: agregar dependencia `lucide-react`.
- `src/components/ui/BottomNav.tsx` (nuevo): Client Component, resalta el
  ítem activo comparando contra `usePathname()`.
- `src/app/(dashboard)/layout.tsx`: renderizar `<BottomNav />` y darle al
  `<main>` padding inferior (`pb-16`) para que el contenido no quede tapado
  detrás de la barra fija.
- `src/app/(dashboard)/mas/page.tsx` (nuevo): links a `/servicios` y
  `/equipo`, más el botón de cerrar sesión (reusa `logoutAction`).
- `src/app/(dashboard)/estadisticas` **no** se toca en esta spec (sigue sin
  `page.tsx`, solo `.gitkeep`) — no forma parte de la barra.
- `src/app/(dashboard)/inicio/page.tsx`: la cabecera pasa de un título fijo
  ("Turnos en curso") al nombre del barbero autenticado + un subtítulo
  estático de cortes/racha (sin datos reales todavía — spec 08).

## 4. Regla de diseño (estricta)

Cero emojis. Cero sombras (nada de `shadow-*`). Solo blanco, la escala de
grises ya tokenizada (`--muted`, `--line`, `--surface-2`) y el acento
"Tinta" (`--accent`) para el ítem activo de la barra — mismos tokens que ya
usa el resto del dashboard (`docs/decisiones.md`, 2026-09-14). El ítem
activo se distingue por color **y** por el grosor de trazo del ícono
(`strokeWidth`), no solo por color, pensando en uso a la luz del día.

## 5. Casos borde

- Ruta activa: `/inicio` no debe marcar "Caja" como activo, y viceversa.
  Comparar por coincidencia exacta de `pathname` (o prefijo, para
  subrutas futuras).
- El botón "Cerrar sesión" que ya existe en la barra superior
  (`layout.tsx`) no se toca ni se duplica de más: queda igual, `/mas` es
  un acceso adicional, no un reemplazo.
